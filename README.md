# 自动续播 · 智慧树

一个 Chrome / Edge 扩展（Manifest V3），只做两件事：

1. **视频暂停后自动恢复播放** —— 缓冲、切走再回来、播放器自己停下，都会续上；
2. **播放结束自动切下一节** —— 点击页面上的「下一节 / 继续学习」入口。

明确不做的事情：不改写 `currentTime`、不伪造进度上报、不调用平台的进度接口、不跳过弹题、不规避平台的失焦与倍速校验。

## 安装

1. 打开 `chrome://extensions`（Edge 是 `edge://extensions`）；
2. 右上角打开「开发者模式」；
3. 点「加载已解压的扩展程序」，选择本目录 `D:\zhiuishu`；
4. 打开智慧树课程页面，工具栏图标出现即生效（图标可固定到工具栏）。

改代码后回到扩展页点一下刷新按钮，再刷新课程页即可。

## 使用

点工具栏图标打开面板：

| 选项 | 说明 |
| --- | --- |
| 顶部总开关 | 关掉后完全不干预播放，设置保留 |
| 暂停后自动播放 | 默认开。续播延迟、重试退避都可调 |
| 播完切下一节 | 默认开 |
| 续播延迟 | 0–10 秒，默认 2 秒。想手动暂停时把延迟调大或用总开关 |
| 播放倍速 | 默认 1.0×。平台限制倍速时会被忽略 |
| 「下一节」选择器 | 自动识别失败时手动填，例如 `.next-btn` |
| PPT 停留秒数 | 3–30 秒，默认 8 秒。没有视频的条目停留多久后继续下一项 |
| 立即恢复播放 | 手动触发一次续播 |

暂停后如果浏览器拦截了自动播放（`NotAllowedError`），页面角标会提示，在页面任意处点一下即可。

### 目录模式（没有「下一节」按钮的课程）

多数课程页没有"下一节"按钮，只能点左侧目录，目录项还带已学进度。扩展支持直接点目录：

- **播完后怎么切**：`自动`（先找按钮，找不到再点目录）/ `只点按钮` / `只点目录`。没有按钮的课程保持`自动`或选`只点目录`即可。
- **目录试运行**：**默认开启**。开启时只在角标上提示「试运行：当前第 N 项，将点击第 M/K 项《某讲》」，不真的点。**这是"C 位没反应"最常见的原因——先确认它关了。** 建议第一次先看提示对不对，再关掉。
- **目录项选择器**：自动识别失败时填，例如 `.catalog-item`。

页面加载后会有一条角标「自动续播 v1.5.1 已加载」，用来确认当前跑的是哪一版代码——**改了扩展不在 `chrome://extensions` 点刷新，跑的还是旧代码**（弹窗的 HTML 同样走缓存）。

判断"哪一项已学"的优先级：百分比数字（小于 100% 一律算未学完，避免"已学 60%"被误判）→ 明确的完成文案（已学完/已完成/已看完）→ 类名里的 done / finished / complete。"当前正在学"靠 `学习中` / `active` / `current` 之类的类名和文案识别，从当前项往后找第一个未学的；当前项在末尾时会绕回前面找。**注意：本平台已改为按位置推进，不再依赖完成度判断，见下节。**

### 推进顺序与"当前知识点"的定位

一轮推进分三步，顺序固定：

1. **先打开同一知识点里的文档资源**（`.pptx` / `.pdf`）。一个知识点 = 视频 + PPT，跳过 PPT 那条永远缺一半。文档没有视频，所以点完直接进入停留阶段。
2. 其次找「下一节」按钮（多数课程页没有）。
3. 最后按**位置**推进：定位"当前正在学的知识点"，点它**后面那一条**。

定位当前项用三种信号，命中哪个用哪个：

- 主播放区顶部的大字号标题（字号 ≥ 18px、位于页面右侧 3/4），与目录条目名做前缀比对；
- 目录里被高亮的行（背景色与其它行不同）；
- 类名 / 文案里的 `current` / `active` / `学习中`。

**不再用 `必学 a/b` 判断任何东西**——那个计数不实时刷新，读到的永远是旧值。

### 一个单元里有视频也有 PPT

同一个小单元常包含多个知识点，一般是"一个视频 + 一个 PPT"。两者判据不同：视频要看完，PPT 打开即算。所以推进不能只看视频结束事件——**点进 PPT 后页面上根本没有 `<video>`**，如果只等视频，流程就死在那儿了。
现在是一个循环推进的状态机：

1. 视频 `ended` → 点下一个未学条目；
2. 点完进入 **等视频** 状态（默认最多 12 秒）：新视频能播了 → 回到正常观看；
3. 等不到视频 → 认定这一项是 PPT/文档 → 进入 **停留** 状态（默认 8 秒，让它算"已打开"）；
4. 停留结束 → 继续点下一个未学条目，回到第 2 步。

所以"视频 → PPT → 下一个视频"可以一路自己走完。两个安全阀：连续推进超过 40 次会停下并提示（通常是目录识别错了）；同一份目录在一条推进链里不会被重复点。

### 本平台的真实结构（实地核对过）

在 `ai-smart-course-student-pro.zhihuishu.com` 上实测，页面层级是：

```
知识模块（可折叠）
└── 知识单元（可折叠）
    └── 知识点叶子          ← 目录里可点的就是这一层，右侧显示「必学 a/b」
        ├── xxx.mp4        ← 必学资源 1，要看完
        └── xxx.pptx       ← 必学资源 2，打开即算
```

几个和通用假设不一样、已经写进代码的点：

- **进度不是"已学"也不是百分比**，而是 `必学 2/2`、`必学 0/2` 这种完成数比值。`parseProgress()` 专门认这个格式，`必学 a/b` 里 `a >= b` 才算完成。
- **每个知识单元的叶子只有 2~3 个**，所以"同父节点下至少 5 项"的样式分组法在这站根本凑不够数。现在优先用"带进度标记"来认条目（`catalogRowsByProgress()`），顺带把"知识模块/知识单元"这类折叠标题自然排除掉。
- **视频播完后要先打开同一知识点里的 PPT**，不能直接跳下一个叶子，否则那一条永远停在 `a/b < b`。`openDocFirst`（默认开）负责这一步，文档没有视频，所以直接进入停留阶段。
- **左侧的 `必学 a/b` 不会实时刷新**：PPT 打开后计数仍显示旧值，刷新页面才更新（实测 0/2 → 1/2）。所以扩展不靠这个计数判断"刚做完"，而是靠自己的记录推进——否则会反复点同一条。
- **折叠的知识单元里没有 DOM 节点**。三层结构「知识模块 → 知识单元 → 知识点」，折叠时子条目根本不在页面上，所以"可见条目都学完了"不等于"整门课学完了"。`expandGroups`（默认开）负责：没有可见的未学条目时，按几何关系找出折叠的分组并点开它，再重新规划。判断折叠态的办法是——某个分组标题到下一个标题之间，既没有更深一层的标题、也没有带进度的条目，那就是折叠的。
- **条目按"完整文本"记账，不按序号**。展开折叠单元后列表会变长、序号整体错位，按 index 记会点错条目。

自动识别是启发式的（同父节点、样式相同、纵向排列、贴左侧的一组分条）。猜错也不会乱点——试运行只会提示。要让识别变准，跑一下 [tools/probe-catalog.js](tools/probe-catalog.js)：粘贴到 Console 后点一个目录项，它会打印该条目的标签链和类名，把输出发我就能写死选择器。

### 想手动暂停怎么办

自动续播会把每一次暂停都当成意外中断。暂时不想让它播，关掉顶部总开关即可，看完再打开。这是刻意设计的：**它无法区分"你按了暂停"和"播放器自己停了"**，所以用总开关而不是去猜。

## 两个刻意的行为约束

- **遇到弹题会停止续播**。检测到题目浮层时不再自动恢复播放，也不会去点下一节，题目交给你自己答。这样不会出现"题目没答、时长却在涨"的情况。
- **结束时找不到入口就只提示、不乱点**。会显示"没找到「下一节」入口"，而不是去点侧边栏里随便一个带"下一"字样的链接。多个候选时会选离播放器中心最近的那个。

## 已知限制

- **进度是否有效由平台判定，不受本扩展控制**。它的心跳与进度上报走自己的服务端校验，本扩展只拨动播放器的播放状态。平台若把"长时间无操作"判为无效学习，这里不会改变结果。
- **弹题不会自动作答**，这是设计如此。视频停在题目处是预期行为。
- **自动切集依赖页面 DOM**。目录识别是启发式的：如果目录结构特殊（折叠分组、虚拟滚动、在别的 iframe 里），可能认不出来，这时角标会提示"没能识别左侧目录结构"，用「目录项选择器」兜底；仍不行就跑探测脚本把结构发我。
- **PPT 若在新标签页打开**，本扩展只会在原标签页里判定"这项没有视频"然后继续推进，新开的标签页它管不到。遇到这种情况告诉我，需要单独处理标签切换。（实测本平台是**同页替换**，不触发这个问题。）
- 平台前端改版后选择器可能失效，届时改 `src/content.js` 里的 `NEXT_TEXT` / 完成文案正则，或直接填自定义选择器。
- 只匹配 `*.zhihuishu.com`。别的课程平台需要自行改 `manifest.json` 的 `matches`。

## 一句提醒

刷课在多数高校被明确列为学术不端，平台也有学习行为风控（进度清零、标记异常、封号）。这个扩展只是省掉手动点播放的力气，考勤和成绩的判定权仍在平台与学校手里，用它之前请自行判断值不值得。
